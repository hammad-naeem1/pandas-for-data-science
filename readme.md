# 🐼 Pandas Data Science Journey

Welcome to my Pandas practice repository! This space tracks my step-by-step progress in learning **Pandas**—the essential Python library for data manipulation, cleaning, exploratory data analysis (EDA), and tabular data handling.

---

## 📂 Repository Structure

The repository is organized by workflow stage, progressing from core structures to full dataset manipulation:

* **`01-series-and-dataframes/`** - Core data structures, creating DataFrames, indexing (`.loc`, `.iloc`), and column operations.
* **`02-data-loading-and-io/`** - Reading and writing data formats (`CSV`, `Excel`, `JSON`, `SQL`).
* **`03-data-cleaning/`** - Handling missing values (`dropna`, `fillna`), deduplication, data type casting, and string formatting.
* **`04-transformation-and-filtering/`** - Filtering rows, conditional logic, sorting, reshaping, and applying functions (`apply`, `map`).
* **`05-grouping-and-aggregation/`** - Multi-level summaries using `groupby`, pivot tables, and custom aggregations.
* **`06-merging-and-joining/`** - Combining datasets via `concat`, `merge`, and `join`.
* **`07-time-series/`** - Working with timestamps, datetime indexing, resampling, and rolling windows.
* **`eda-mini-projects/`** - Practical Exploratory Data Analysis on real-world datasets (e.g., Titanic, Housing Prices, Superstore Sales).

---
